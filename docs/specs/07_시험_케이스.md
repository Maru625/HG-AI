## 4. 최근 실행

- 58개 통과 (Python 3.12, 약 70초). 10/23 규정 확장 전에는 32개였다(규정 대응 +19, 가위바위보 +7).
- 손으로 확인한 것: Playwright로 화면 10종 캡처(1366px·390px), 자동 갱신(화면 밖 저장이 3초 안에 반영), 토스트 닫기, 승인·반려 확인창, streamable HTTP 연결(결재자용, 경로 비밀값).
- 10/23 손으로 확인한 것: 새 기안(사례 표, 1440px·760px), 작성 양식 3종(출장비·결과보고·회의실), 원본 대조 체크가 있는 초안, 사유 입력 띠, 결재 검토의 처리 기한·지연 알리기·합의 버튼, 기안자 결과·지연 알림, 처리 기한 경과 결재함, 규정 화면의 조항별 대응, 시연 제어 패널의 연결 8개.
