## 2. 시연 전 준비 (체크리스트)

1. `uv run approval-server reset` → `uv run approval-server` (전결 서버 + 웹 화면, http://localhost:8000)
2. Claude Desktop 설정에 연결 2개를 넣는다(README 4장). 설정 예는 시연 제어 패널(`/demo`)이나 `uv run approval-server connections`에서 복사한다.
3. Claude Desktop에서 대화 2개를 준비한다.
   - 대화 A(기안자): `approval-drafter`만 켜고 `approval-approver`는 끈다.
   - 대화 B(결재자): `approval-approver`만 켠다.
   - [해석] 기안 툴과 결재 조회 툴은 연결별로 나뉘어 섞이지 않는다. 다만 공통 툴 6개(`whoami`, `get_status` 등)는 두 연결에 다 있어, 한 대화에 둘 다 켜 두면 어느 명의로 부를지 AI가 고른다. 대화별로 하나만 켜면 이 혼선이 없다.
4. 브라우저 창 2개: 왼쪽에 채팅, 오른쪽에 웹 화면. 웹 화면 오른쪽 위 사용자 선택을 **김지훈 선임**으로 둔다.
5. 시연 제어 패널에서 확인 방식이 **A(채팅에서 확인)**, 시연 시계가 11-12 10:00 근처인지 본다.

## 5. 막혔을 때

| 상황 | 대응 |
|---|---|
| AI가 순서를 건너뛴다 | 서버 오류 코드와 fix_hint가 다음 할 일을 알려 준다. 그대로 두면 AI가 스스로 고친다. 이것도 시연 포인트다 |
| AI가 사유·담당을 지어내려 한다 | "그건 내가 알려 줄게"라고 말하고 값을 준다. 서버는 사유 없는 한도 초과를 오류로 막는다 |
| 데이터가 꼬였다 | 시연 제어 패널 → 처음 상태로 초기화(시계도 11-12 10:00으로) |
| 툴이 안 보인다 | Claude Desktop을 완전히 종료 후 다시 연다. 전결 서버가 먼저 켜져 있어야 연결 역할을 확인한다(꺼져 있으면 APPROVAL_ROLE 값으로 등록) |
| SERVER_UNAVAILABLE | 전결 서버를 켠다 (`uv run approval-server`) |
