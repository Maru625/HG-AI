## 2. 시연 전 준비 (체크리스트) — 10/26 개정

**시연은 A(발표 PC 혼자)로 확정(10/26).** B·C는 확장용으로 준비만 해 두었다. 셋 다 같은 프로그램이고, 다른 것은 "누가 어디서 접속하느냐"뿐이다. 가위바위보는 A에서 발표 PC의 일반 창(도전자)과 InPrivate 창(수비자, 문채원 팀장) 두 개로 한다(창마다 사용자 선택이 따로).

| 실행 방식 | 언제 | 켜는 법 | 웹 화면 | ChatGPT에 등록할 MCP 주소 |
|---|---|---|---|---|
| A. 발표 PC 혼자 (기본) | 발표자 한 사람이 시연 | `start_gpt_demo.bat` 더블클릭 | `http://localhost:8000` | `http://127.0.0.1:8765/mcp/<비밀값>/drafter`, `…/approver` |
| B. 같은 와이파이 | 청중·조원이 각자 PC에서 같이 해 봄 | `start_lan_demo.bat` 더블클릭 (첫 실행 때 Windows 방화벽 '개인 네트워크' 허용) | `http://<발표 PC IP>:8000` | 발표 PC는 A와 같음, 다른 PC는 `http://<발표 PC IP>:8765/mcp/…` |
| C. 서버 배포 | 연수 기간 내내 여러 사람이 씀 | 서버에서 `deploy/` 폴더 `docker compose up -d --build` (09 문서) | `https://<도메인>` | `https://<도메인>/mcp/<비밀값>/…` 또는 `…/mcp` + 헤더 토큰 |

1. 고른 방식으로 서버를 켠다. A·B는 켤 때마다 데이터가 처음 상태로 돌아가고(시연 시계 11-12 10:00), 검은 창에 등록 주소가 나온다. **창을 닫으면 꺼진다.**
2. 등록 주소는 웹 상단 **AI 연결** 메뉴에서 복사한다(지금 고른 사용자의 연결이 강조된다). 비밀값은 `data/mcp_secret.txt`에 남아 다시 켜도 같으므로, 한 번 등록한 PC는 다시 할 필요 없다.
3. ChatGPT 데스크톱 앱 › 설정 › 플러그인 › 추가 › MCP 서버 추가 › **스트리밍 가능한 HTTP**로 `approval_drafter`, `approval_approver`를 등록한다. 서버 코드가 바뀐 뒤(10/23 확인 ② 입력 변경 등)에는 연결을 껐다 켜서 **툴 목록을 새로 받는다**.
4. ChatGPT Work 대화 2개를 준비한다.
   - 대화 A(기안자): `approval_drafter`만 켠다. 대화 B(결재자): `approval_approver`만 켠다.
   - [해석] 공통 툴 6개(`whoami`, `get_status` 등)는 두 연결에 다 있어, 한 대화에 둘 다 켜 두면 어느 명의로 부를지 AI가 고른다. 대화별로 하나만 켜면 이 혼선이 없다.
5. 화면 배치: 왼쪽에 ChatGPT, 오른쪽에 웹 화면. 웹 화면 오른쪽 위 사용자를 **김지훈 선임**으로 둔다.
6. 시연 제어 패널(`/demo`)에서 확인 방식 **A(채팅에서 확인)**, 시연 시계 11-12 10:00 근처, **회의실 가위바위보 켜짐**(선택 장면에 쓸 때)을 본다. C 방식은 운영자 키를 넣어야 바꿀 수 있다.
7. B·C 방식이면 참가자에게 웹 주소(필요하면 입장 코드)만 알려 준다. 참가자는 각자 사용자를 고르고, AI까지 쓰려면 **AI 연결** 화면의 주소를 자기 ChatGPT에 등록한다. 같은 사용자를 여럿이 고르면 같은 초안·결재함을 함께 본다.

> **[변경] 10/20 판 → 10/26 판**: 이전 체크리스트는 Claude Desktop 기준이었다 — "① `approval-server reset` → `approval-server` ② Claude Desktop 설정에 연결 2개(README 4장, `/demo`·`approval-server connections`에서 복사) ③ 대화 A는 `approval-drafter`만, 대화 B는 `approval-approver`만 켬 ④ 브라우저 창 2개, 사용자 김지훈 ⑤ 확인 방식 A, 시계 확인". 시연 수단을 ChatGPT 데스크톱 앱 + MCP(HTTP)로 정했고(10/20), 배포 대비로 실행 방식 B·C, AI 연결 화면, 툴 목록 새로 받기, 가위바위보 켜짐 확인이 더해졌다. Claude Desktop(stdio)은 README 5장의 예비 경로로 남는다.
