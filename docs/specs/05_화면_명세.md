# 05. 화면 명세

> 기준: 설계서 9장. 코드: `web/routes.py`, `web/templates/`, `web/static/`. 값은 모두 서비스 계층(`core/services.py`)에서 받는다.
> 화면은 밝은 테마 하나, 외부 CDN 없이 동작한다(htmx 2.0.4, Chart.js 4.4.7을 `web/static/vendor/`에 둠).
> 2026-10-23: 토스 스타일 시안(Stitch `DESIGN.md`)의 색·모서리·카드·칩을 적용했다. 시안의 웹폰트, 표 안 승인 버튼, 지어낸 수치·카드는 가져오지 않았다(아래 5장).

## 2. 공통

- **상단바**: 홈·작업 계획·임시저장함·결재함·회의실·규정·작업 기록, 'DEMO · 더미 데이터' 표시, 시연 시계(누르면 제어 패널), 알림 버튼, 역할 칩(결재자/기안자)과 사용자 전환(김지훈 선임 · 박서연 팀장 · 이도현 실장 · 윤재민 팀장 · 정하늘 책임). 사용자는 쿠키 `demo_user`로 기억한다. 역할 칩은 직책(팀장·실장)으로 정한 시연용 표시다.
- **AI 작성 배지**: 계획·문서를 MCP로 만들거나 고쳤으면 보라색 'AI 작성'.
- **자동 갱신**: `main#live`를 3초마다 htmx로 다시 받아 바꾼다. 입력 칸에 커서가 있거나 펼친 내용(details)이 있거나 탭이 가려져 있으면 쉬어서, 쓰던 것이 날아가지 않게 했다.
- **알림**: 상단바 안 '알림' 버튼(읽지 않은 수)이 4초마다 갱신된다. 읽지 않은 최신 알림은 상단바 아래에 펼쳐져(`#notice`) 본문을 덮지 않는다. 4초 갱신 응답 하나로 버튼은 `hx-select=".bellbar"`, 펼침은 `hx-select-oob="#notice"`로 바꾼다.
  - 긴급(빨간 띠) / 정기(노란 띠), 알림 사유, 결재할 문서 전체를 중요도순으로 7건까지.
  - [결재함에서 보기]는 읽음 처리 후 결재함으로, [×]는 읽음 처리만.
- **오류**: 버튼 작업이 막히면 같은 화면 위에 빨간 띠로 메시지와 다음 할 일을 보여준다. 권한 없는 화면은 오류 화면과 '사용자 전환' 안내.

## 3. 강조와 접근성

- 색 토큰(2026-10-23 한화 색상표 적용): 주요 한화 오렌지 #f37321(100%)·#f89b6c(70%)·#fbb584(50%), 글자 한화 블랙 #000000·#4a4a4a·#767676, 바탕 #f4f4f4, 카드 흰색 + 1px #e6e6e6 + 모서리 16px. 흰 바탕 위 오렌지 글자·링크는 대비를 위해 진한 오렌지 #c2540a(4.6:1), 오렌지 면 위 글자는 검정(7.3:1). 의미 색: 승인 #e8f8f0/#0d7a3e, 대기·주의는 오렌지와 구분되게 노랑 #fff8db/#7a5a00, 반려·오류 #feeceb/#b42318, 작성완료·사람(화면) 파랑 #eaf1fd/#1f56b3. AI 표시는 보라 #7048e8.
- 중요도 칩: 긴급 = 빨강 + "!" / 보통 = 노랑 + "◆" / 낮음 = 회색 + "·". 색과 함께 글자·기호가 있어 색만으로 구분하지 않는다(설계서 9장).
- 주의 행: 노란 바탕 + 왼쪽 굵은 띠 + 굵은 글자 + "⚠ 주의" 글자.
- 상태 배지: 작성중(빨강)·작성완료(파랑)·확인완료/승인(초록)·결재대기/가예약(노랑)·취소/해제(회색 + 취소선).
- 그래프: 부서별 야근 막대는 전결 처리만 한화 오렌지 #f37321, 나머지 원인은 회색 단계(#4a4a4a·#8c8c8c·#c4c4c4, 밝기로 구분). 단일 계열 막대(설문·반려 사유·예상 절감)는 오렌지. 막대 끝 값과 '표로 보기'를 함께 둔다. 직급×단계 표는 오렌지 진하기(#fff3eb → #fbb584 → #f37321 → #c2540a, 칸 사이 4px)로 크기를 나타낸다.
- 좁은 화면(390px)에서 가로 넘침이 없도록 표는 자체 가로 스크롤.

## 4. 승인·반려

- 결재 검토 화면의 결정 바에서만 한다. REST API와 MCP에는 이 기능이 없다(설계서 3.2).
- 반려는 의견이 있어야 한다(화면과 서버 둘 다 확인).
- 차례가 아닌 사람이 열면 결정 바가 없고 "지금은 결재할 차례가 아닙니다"를 보여준다.
