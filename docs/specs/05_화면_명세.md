# 05. 화면 명세

> 기준: 설계서 9장. 코드: `web/routes.py`, `web/templates/`, `web/static/`. 값은 모두 서비스 계층(`core/services.py`)에서 받는다.
> 화면은 밝은 테마 하나, 외부 CDN 없이 동작한다(htmx 2.0.4, Chart.js 4.4.7을 `web/static/vendor/`에 둠).
> 2026-10-23: 토스 스타일 시안(Stitch `DESIGN.md`)의 색·모서리·카드·칩을 적용했다. 시안의 웹폰트, 표 안 승인 버튼, 지어낸 수치·카드는 가져오지 않았다(아래 5장).
> 2026-10-23 규정 확장: 새 기안(직접 작성·사례), 고치기, 사유 입력, 원본 대조 확인, 화면 상신, 초안 취소, 반려 후 다시 기안, 처리 기한·지연 알림, 합의 버튼, 기안자 알림, 사용자 전환 묶음, 규정 화면의 조항별 대응을 더했다(아래 6장).

## 2. 공통

- **상단바**: 홈·새 기안·작업 계획·임시저장함·결재함·회의실·규정·작업 기록, 'DEMO · 더미 데이터' 표시, 시연 시계(누르면 제어 패널), 알림 버튼, 역할 칩(결재자/기안자)과 사용자 전환. 사용자는 쿠키 `demo_user`로 기억한다. 창 폭 1520px 이하에서는 메뉴가 둘째 줄로 내려간다.
  - 사용자 전환 묶음(10/23): 기안자 — 김지훈 선임·정하늘 책임·오세준 사원(연구1팀), 송서준 선임(경영지원팀) / 결재자 — 박서연 팀장, 이도현 실장, 최민준 본부장, 윤재민 팀장(경영지원팀), 서지원 실장, 임동욱 본부장, 강민호 팀장, 문채원 팀장. 이름 옆에 부서를 붙인다.
  - 역할 칩은 직책(팀장·실장·본부장)으로 정한 시연용 표시다. 결재자도 화면에서 기안할 수 있다(제3조 사례).
  - 이전(10/23 오전): 메뉴에 '새 기안'이 없었고, 사용자 전환은 김지훈 선임 · 박서연 팀장 · 이도현 실장 · 윤재민 팀장 · 정하늘 책임 5명이었다.
- **AI 작성 배지**: 계획·문서를 MCP로 만들거나 고쳤으면 보라색 'AI 작성'.
- **자동 갱신**: `main#live`를 3초마다 htmx로 다시 받아 바꾼다. 입력 칸에 커서가 있거나, 값을 바꾼 양식이 있거나(사유 입력·원본 대조 체크·지연 사유), 펼친 내용(details)이 있거나, 탭이 가려져 있으면 쉬어서 쓰던 것이 날아가지 않게 했다. 작성 양식(새 기안·고치기)은 자동 갱신하지 않는다.
- **알림**: 상단바 안 '알림' 버튼(읽지 않은 수)이 4초마다 갱신된다. 읽지 않은 최신 알림은 상단바 아래에 펼쳐져(`#notice`) 본문을 덮지 않는다. 4초 갱신 응답 하나로 버튼은 `hx-select=".bellbar"`, 펼침은 `hx-select-oob="#notice"`로 바꾼다.
  - 결재자: 긴급(빨간 띠) / 정기(노란 띠), 알림 사유, 결재할 문서 전체를 중요도순으로 7건까지(기한 경과 표시). [결재함에서 보기]는 읽음 처리 후 결재함으로.
  - 기안자(10/23): 결재 결과(승인 초록 띠·반려 빨간 띠, 반려 사유) / 처리 지연(파란 띠, 지연 사유·처리 예정일). [문서 보기]는 읽음 처리 후 그 문서로.
  - [×]는 읽음 처리만.
- **오류**: 버튼 작업이 막히면 같은 화면 위에 빨간 띠로 메시지와 다음 할 일을 보여준다. 권한 없는 화면은 오류 화면과 '사용자 전환' 안내.

## 3. 강조와 접근성

- 색 토큰(2026-10-23 한화 색상표 적용): 주요 한화 오렌지 #f37321(100%)·#f89b6c(70%)·#fbb584(50%), 글자 한화 블랙 #000000·#4a4a4a·#767676, 바탕 #f4f4f4, 카드 흰색 + 1px #e6e6e6 + 모서리 16px. 흰 바탕 위 오렌지 글자·링크는 대비를 위해 진한 오렌지 #c2540a(4.6:1), 오렌지 면 위 글자는 검정(7.3:1). 의미 색: 승인 #e8f8f0/#0d7a3e, 대기·주의는 오렌지와 구분되게 노랑 #fff8db/#7a5a00, 반려·오류 #feeceb/#b42318, 작성완료·사람(화면) 파랑 #eaf1fd/#1f56b3. AI 표시는 보라 #7048e8.
- 중요도 칩: 긴급 = 빨강 + "!" / 보통 = 노랑 + "◆" / 낮음 = 회색 + "·". 색과 함께 글자·기호가 있어 색만으로 구분하지 않는다(설계서 9장).
- 주의 행: 노란 바탕 + 왼쪽 굵은 띠 + 굵은 글자 + "⚠ 주의" 글자.
- 상태 배지: 작성중(빨강)·작성완료(파랑)·확인완료/승인(초록)·결재대기/가예약(노랑)·취소/해제(회색 + 취소선).
- 그래프: 부서별 야근 막대는 전결 처리만 한화 오렌지 #f37321, 나머지 원인은 회색 단계(#4a4a4a·#8c8c8c·#c4c4c4, 밝기로 구분). 단일 계열 막대(설문·반려 사유·예상 절감)는 오렌지. 막대 끝 값과 '표로 보기'를 함께 둔다. 직급×단계 표는 오렌지 진하기(#fff3eb → #fbb584 → #f37321 → #c2540a, 칸 사이 4px)로 크기를 나타낸다.
- 좁은 화면(390px)에서 가로 넘침이 없도록 표는 자체 가로 스크롤.

## 4. 승인·반려

- 결재 검토 화면의 결정 바에서만 한다. REST API와 MCP에는 이 기능이 없다(설계서 3.2).
- 반려는 의견이 있어야 한다(화면과 서버 둘 다 확인).
- 차례가 아닌 사람이 열면 결정 바가 없고 "지금은 결재할 차례가 아닙니다"를 보여준다.

| 내용 확인 ② | `/drafts/{id}/confirm` (`original_checked` 체크값) | 본인 초안 | `confirm_draft_ui` | 판독 신뢰도가 낮은 증빙마다 원본 대조 체크가 있어야 한다(제22조). 없으면 빨간 띠로 ORIGINAL_CHECK_REQUIRED 안내, 작업 기록에 막힌 시도 |
| 상신 ③ | `/drafts/{id}/submit` | 화면에서 쓴 본인 초안 | `submit_draft_ui` | AI가 쓴 초안은 FORBIDDEN(대화에서 상신). 회의실이면 가예약, 긴급이면 결재자 즉시 알림 |
| 초안 취소 | `/drafts/{id}/cancel` | 본인 초안(상신 전) | `cancel_draft_ui` | 확인창 후 취소 |
| 고쳐서 다시 기안 | `/docs/{id}/redraft` | 반려된 본인 문서 | `redraft_ui` | 값·증빙·사유를 옮긴 새 초안(original_doc_id), 두 번 눌러도 하나 |
| 처리 지연 알리기 | `/review/{id}/delay` (사유, 처리 예정일) | 지금 차례인 결재자 | `notify_delay` | 웹 화면에서만(제4조). 결재는 그대로 대기, 기안자에게 DELAY 알림 |
| 합의 | `/review/{id}/decide` (`kind=합의`) | 합의 차례인 부서장 | `decide` | 버튼 이름만 다르고 승인·반려와 같다. 합의하지 않으면 사유 필수, 문서 반려 |

## 7. 회의실 가위바위보 대결 (재미 기능, 2026-10-23)

규정에 없는 재미 기능이다. 시연 제어 패널에서 켜고 끈다(기본 켜짐). AI 연결(MCP·REST)로는 열지 않는다.

| 장면 | 화면 | 내용 |
|---|---|---|
| 도전 | 회의실 신청 초안(`/drafts/{id}`) | 겹치는 예약마다 '이 시간을 꼭 써야 한다면?' 카드와 [⚔️ 가위바위보로 도전]. 도전할 수 없으면 이유(내 예약, 다른 오류가 있음, 이미 져서 다시 못 함, 다른 사람이 도전 중) |
| 대결 창 | 모든 화면 위 전체 덮개(`#duel-root`, `web/static/duel.js`·`duel.css`) | 1.5~3초마다 `/duel/state`를 보고 지금 사용자의 대결을 띄운다. 예능 자막 × 오락실 대전 화면: 햇살 무늬 배경, 깜박이는 전구 테두리, '회의실 쟁탈전' 자막, 걸린 자리(트로피 띠), 나(왼쪽·오렌지) VS 상대(오른쪽·파랑), 큰 가위·바위·보 버튼, 소리 끄기, [도전 취소]/[양보하기]/[나중에](오른쪽 아래 배지로 접힘) |
| 수비자 첫 화면 | 대결 창 | 경보음과 '⚔ 도전장!' 자막, "지면 예약이 넘어갑니다" |
| 공개 | 대결 창 | 둘 다 고르면 "가위!" "바위!" "보!!!" 자막이 화면을 치고(흔들림·북소리), 두 손이 양쪽에서 날아와 부딪친다("쾅!", 섬광, 불꽃). 비기면 "비겼다!! 한 판 더!" |
| 결판 | 대결 창 | 이긴 쪽: 무지개 '이겼다!!!', 꽃가루 대포·불꽃놀이·왕관, 팡파르. 진 쪽: 'K.O.' 도장, 😭 비, 슬픈 나팔. 결과 문장과 [초안으로 가기]/[회의실 현황 보기]·[확인] |
| 흔적 | 회의실 현황·문서 화면 | 예약 칸과 해제 목록에 ⚔️ 메모(승리 가예약, 패배로 해제, 방어 성공 n회), 취소된 신청 문서에 사유 |

- 상대의 선택은 둘 다 고르기 전까지 서버가 화면에 보내지 않는다. 소리는 화면을 한 번 누른 뒤부터 난다(브라우저 자동 재생 제한). 움직임 줄이기 설정이면 흔들림을 줄인다.
- 시연(브라우저 하나): 도전자로 고른 뒤 오른쪽 위 사용자 전환에서 수비자로 바꾸면 대결 창이 뜬다. 두 사람이 각자 브라우저로 하면 동시에 진행된다.
