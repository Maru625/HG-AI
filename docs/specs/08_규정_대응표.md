# 08. 규정 대응표

> 2026-10-23 새로 만듦. 위임전결규정(더미)의 조항마다 이 시스템이 무엇으로 대응하는지, 화면에서 바로 해 볼 수 있는 사례가 무엇인지 정리한다.
> 원본: `core/cases.py`(`ARTICLE_FEATURES`, `presets`). 웹 화면 '규정'의 조항별 대응과 '새 기안'의 사례 목록이 같은 원본을 쓴다.
> 시험: `tests/test_regulations_cover.py` — 조항마다 대응이 있는지, 사례가 아래 '서버 규칙 코드'와 '기대 결재선'대로 걸리는지(시연 시계를 평일·토요일·다음 주로 옮겨도) 확인한다.

## 1. 해 보는 법

| 방법 | 어디서 | 쓰임 |
|---|---|---|
| 화면에서 직접 | 상단 메뉴 **새 기안**(`/new`) → 사례 [시작] 또는 [빈 양식으로 작성] | 값이 미리 채워진 양식 → [저장하고 검증] → 초안 화면에서 사유 입력·원본 대조·[내용 확인]·[상신] |
| AI 대화로 | 기안자용 연결(여러 사례용 연결은 README 4.3) | 같은 규칙이 MCP 툴 결과의 오류·경고로 돌아온다 |
| 결재 쪽 | 상단 사용자 전환(결재자 묶음) | 결재 검토 화면에서 승인·반려·합의·처리 지연 알림 |

- 특정 사용자로 해야 의미가 있는 사례(직급별 숙박 상한, 팀장·실장 기안, 중복 영수증)는 [○○으로 바꿔 시작] 버튼이 사용자를 바꾸고 양식을 연다.
- 화면에서 쓴 문서는 화면에서 상신한다. AI가 쓴 문서의 상신(확인 ③)은 지금처럼 대화에서 한다(설계서 4장).

## 4. 결재 쪽 사례 (제3조·제4조·제14조)

| 사례 | 하는 법 | 기대 결과 |
|---|---|---|
| 처리 기한 표시 (제4조) | 아무 문서나 상신 → 결재자로 바꿔 결재함·결재 검토 | 결재 차례가 온 날부터 3영업일: "처리 기한 11-17 (D-3)" |
| 처리 기한 경과 → 긴급 (제4조) | 시연 제어 패널에서 시계를 +1일씩 옮김 | 3영업일을 넘기면 "처리 기한 11-17 경과", 중요도 긴급, 결재자에게 즉시 알림(대기 결재 전체를 묶어서) |
| 처리 지연 알림 (제4조) | 결재 검토 화면 오른쪽 [처리 지연 알리기]에 사유(와 처리 예정일) | 기안자 알림 '처리 지연 알림', 문서 화면 노란 띠, 결재함 '올린 문서'에 사유 표시. 결재는 그대로 대기 |
| 단계별 기한 (제4조) | 2단계 이상 문서(`pur01-office` 등)에서 1단계 승인 | 다음 결재자의 기한은 그 사람에게 차례가 온 날부터 다시 3영업일 |
| 여러 단계·본부장 (제3조) | `exp01-division`, `pur01-division` 상신 → 박서연 팀장 → 이도현 실장 → 최민준 본부장 → (합의) 윤재민 팀장 | 단계마다 다음 결재자의 결재함으로 넘어감 |

| 반려 → 다시 기안 | 반려된 문서 화면 [고쳐서 다시 기안] | 원문서를 잇는 새 초안(값·증빙·사유 복사) → 고쳐서 상신 → 결재자에게 '재상신 변경점' |

## 5. 해석으로 정한 것

규정 문구만으로 정해지지 않아 이 시스템이 정한 것이다. 실제 도입 때는 규정 담당 부서의 확인이 필요하다.

| 조항 | 규정 문구 | 이 시스템의 해석 |
|---|---|---|
| 제3조 | "바로 위 직책자가 결재한다" | 팀장이 기안하면 실장, 실장이 기안하면 본부장. 본부장(이 조직도의 최상위)은 결재할 사람이 없어 상신하지 못하게 막는다 |
| 제3조 | "결재선 끝에 합의 부서장을 둔다" | 합의 부서장이 기안자이거나 이미 결재선에 있으면 합의 단계를 따로 두지 않는다(같은 사람이 두 번 보지 않게) |
| 제4조 | "상신일로부터 3영업일 안에 처리" | 상신일(차례가 온 날) + 3영업일이 처리 기한. 그날까지는 기한 안, 다음 영업일부터 경과 |
| 제12조 | "출장 종료 후 5영업일 안" | 출장 종료일 + 5영업일이 기한. 지나도 상신은 되고 경고와 결재자 주의 항목으로 남긴다(기존과 같음) |
| 제13조 | "구매 전에 ... 요청한다" | 구매 시점 대신 희망 납기로 판단한다. 희망 납기가 오늘 이전이면 막는다 |
| 제14조 | "업무시간(09:00~18:00) 밖에 쓰는 경우" | 주말·공휴일 사용도 업무시간 밖으로 보고 경영지원팀 합의를 넣는다 |
| 제14조 | "사용 신청 후 ... 사용한다" | 시작 시각이 이미 지난 신청은 막는다 |
| 제20조 | "영수증 원본 또는 사본을 첨부한다" | 시연에서는 파일을 올리지 않고 파일 이름만 기록한다. 증빙이 필수인 프로세스에서 이름이 비면 첨부 누락이다. AI는 파일 이름을 모르면 "대화 첨부 이미지 3"처럼 어느 첨부인지 적는다 |
| 제22조 | "기안자가 원본을 확인하고" | 확인 ② 때 기안자가 원본(종이 영수증·카드 사용 내역)과 대조했다고 표시하는 것으로 기록한다. 원본을 다시 올리라고 하지 않는다 |
| (공통) | — | 증빙 날짜가 오늘(시연 시계)보다 뒤면 오류로 막는다. 규정에 따로 적힌 것은 아니고, 사용 후 정산(제10·11조)과 맞추려는 것이다 |
| 제20조 | "이미 정산한 증빙" | 같은 기안자의 상신·승인 문서 기준(기존 보완 유지, 02 문서 2장) |
