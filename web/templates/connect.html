등록 순서 ChatGPT 데스크톱 앱

  1. 아래 표에서 연결을 고릅니다기안은 기안자용(툴 14개), 결재 검토는 결재자용(읽기 툴 8개)입니다.
  2. MCP 서버 추가 창을 엽니다설정 › 플러그인 › 추가 › MCP 서버 추가. 앱 버전에 따라 설정 › MCP 서버 › 서버 추가입니다.
  3. 스트리밍 가능한 HTTP로 등록합니다이름과 URL을 아래에서 복사해 붙입니다. 인증은 비워 둡니다(주소 안 비밀값이 토큰 역할).
  4. 새 대화에서 연결 하나만 켜고 시작합니다첫 메시지에 연결 이름을 말합니다. 예: “기안자 연결(approval_drafter)로 지난주 대전 출장 정산해 줘.”

알아 둘 것

  • 대화마다 연결은 하나만 켭니다. 기안자·결재자 연결이 함께 켜져 있으면 AI가 다른 연결을 고를 수 있습니다.
  • 서버가 바뀐 뒤 툴이 이상하면 연결을 껐다 켜서 툴 목록을 새로 받습니다.
  • 같은 연결을 여러 사람이 쓰면 같은 사람으로 일하므로 초안·결재함을 함께 봅니다.
  • 주소와 토큰은 이 서버를 쓰는 사람끼리만 나눕니다. 시연이 끝나면 운영자가 비밀값을 바꿔 모두 무효로 합니다.
